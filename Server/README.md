# Project A Backend Stub

This folder contains a tiny local backend stub for Project A.

## Run locally

1. Install Node.js 18+.
2. From this folder run:
   ```bash
   npm install
   npm run dev
   ```
3. Backend starts on `http://localhost:8080`.

## Endpoints

- `GET /health` returns backend status.
- `GET /rooms` returns a sample room list.

Use this while Unity client integration is still in progress.
